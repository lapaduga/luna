# Луна — ИИ-ассистентка по менструальному циклу

Чат-приложение на Express + DeepSeek с эшелонированной защитой от промпт-инъекций
и утечек секретов. Это учебный проект: цель — показать, как детерминированные гейты,
аудит и осторожный промпт-инжиниринг закрывают основные векторы LLM-атак.

## Возможности

- **Дашборд** — текущая фаза цикла, прогресс, прогноз следующего периода.
- **Календарь** — отметка начала периода и симптомов.
- **Чат с ИИ** — живой SSE-стрим ответов, подсказки-чипы, история диалога в localStorage.
- **Безопасность** — входной и выходной гейты, токен-бюджет, аудит-лог с маской (см. ниже).

## Требования

- Node.js ≥ 18
- Ключ API DeepSeek (бесплатный: <https://platform.deepseek.com/api_keys>)

## Локальный запуск

```bash
git clone https://github.com/lapaduga/luna.git
cd luna
npm install
cp .env.example .env
```

Откройте `.env` и впишите в переменную `DEEPSEEK_API_KEY` **свой** ключ с
<https://platform.deepseek.com/api_keys> (образец заполнения — в `.env.example`).

Запуск:

```bash
node server.js
# или: npm start
```

Приложение доступно на <http://127.0.0.1:3000> (сервер слушает только localhost).

## Проверка после запуска

- Health-эндпоинт: `http://127.0.0.1:3000/api/health` — покажет модель, режим гейтов и счётчики.
- Red-team прогон против локального сервера:

```bash
node scripts/redteam.js http://127.0.0.1:3000
```

Ожидаемый результат — все кейсы помечаются как заблокированные/пропущенные корректно.

## Тесты

```bash
npm test
```

Unit-тесты гейтов (вход/выход: секреты, инъекции, PII) в `tests/guards.test.js`.

## Безопасность: как это устроено

Вход:

- **Секреты** (ключи, токены, карты) на входе блокируются (или маскируются — режим `mask`).
- **Инъекции** (DAN, instruction override, extraction, инъекция через данные цикла) — блокируются
  детерминированными эвристиками; спорные случаи можно докрутить LLM-классификатором (`GUARD_LLM=1`).

Выход (гибридный стрим):

- Ответ идёт живым потоком, но с **окном-задержкой** (~140 символов): фрагмент секрета не успевает
  дойти до клиента — гейт обрывает или маскирует его целиком.
- PII (email, телефон) маскируются; `[REDACTED_*]`-маркеры видны клиенту, оригинал — только в логе с маской.
- Секреты никогда не лежат в системном промпте; canary-токен помогает поймать утечку промпта.

Аудит и бюджет:

- `gateway.log` (JSONL) — кто, что, когда спрашивал, токены и стоимость. Все секреты замаскированы.
- Токен-бюджет на IP в час (`TOKEN_BUDGET_PER_HOUR`) — защита от исчерпания счёта.
- Подробное описание угроз и архитектуры — в [`SECURITY_PROMPT.md`](SECURITY_PROMPT.md).

### Важно

- `.env` и `.env.production` в `.gitignore` — **никогда не коммитьте ключи**.
- `gateway.log` в `.gitignore` — логи не попадают в репозиторий.
- Если ключ где-то засветился (коммит, чат, логи) — сразу перевыпустите его на
  <https://platform.deepseek.com/api_keys> и обновите `.env`.
- Известное ограничение: обфусцированные/разбитые фрагменты секрета (например, ключ, разбитый
  переносом строки) детектятся не полностью — это сознательный компромисс, задокументирован в `SECURITY_PROMPT.md`.

## Структура проекта

```
server.js            — шлюз: гейты, SSE-стрим, аудит, health
guards.js            — чистые функции детекта/маскирования (без I/O)
public/              — фронтенд (index.html, styles.css, app.js, chat.js, cycle.js)
tests/guards.test.js — unit-тесты гейтов
scripts/redteam.js   — e2e red-team против /api/chat
.env.example         — шаблон конфигурации
```

## Адаптив

Интерфейс свёрстан под мобильные (320px+): подсказки-чипы скроллятся по горизонтали и скрываются,
как только появляется история диалога, чтобы не съедать место под чат.
